# Sky KTX Tool

Инструменты на Python для текстур `.ktx` из ПК-версии *Sky: Children of the Light*: посмотреть, вытащить в PNG, собрать обратно и увеличить до 8K.

Главное здесь — графическая программа `ktx_tool_gui.py`. Два консольных скрипта остались от первых версий и работают только с BC7.

## Что умеет `ktx_tool_gui.py`

Три вкладки:

- **Decode** — открыть `.ktx`, увидеть превью, сохранить в PNG.
- **Encode** — взять свою картинку (PNG/JPG) и оригинальный `.ktx`, собрать новый `.ktx` в том же формате. По желанию картинку можно растянуть до 2K, 4K или 8K.
- **Upscale 8K** — одна кнопка: декодировать `.ktx`, увеличить, закодировать обратно.

Остальное:

- Кодирование идёт параллельно на всех ядрах процессора. Текстура 8K собирается за секунды, а не за минуты.
- Формат берётся из оригинального файла, а не всегда BC7.
- Если в оригинале были мип-уровни, они создаются заново под новый размер.
- Фильтры увеличения: Lanczos, Bicubic, Nearest.
- Работа идёт в фоне с прогресс-баром, окно не зависает.
- Программа ничего не перезаписывает сама: результат сохраняется через «Save as», оригинал игры остаётся на месте.

## Поддерживаемые форматы

| Формат | Код OpenGL | Чтение | Запись |
|---|---|---|---|
| BC7 sRGB | `0x8E8D` | да | да (mode 6) |
| BC7 linear | `0x8E8C` | да | да (mode 6) |
| BC4 / RGTC1 | `0x8DBB` | да | да |
| RGBA8 без сжатия | `0x8058` | да | да |

Только KTX версии 1 и только обычные двумерные текстуры (не кубические карты и не массивы).

BC5, ASTC (мобильные версии игры) и KTX2 не поддерживаются.

## Установка и запуск

Нужен Python 3.8 или новее.

```
pip install Pillow numpy
python ktx_tool_gui.py
```

Текстуры игры лежат в `data/assets/<пакет>/Data/Images/Bin/BC/`.

## Как заменить текстуру в игре

1. Сделайте копию оригинального `.ktx`.
2. Во вкладке **Decode** сохраните его в PNG и отредактируйте.
3. Во вкладке **Encode** выберите оригинальный `.ktx` и свою картинку, нажмите Encode, затем «Save as .ktx».
4. Положите новый файл на место оригинала под тем же именем.

## Что стоит знать заранее

- BC7 пишется только в режиме 6. Он хорошо держит плавные градиенты и прозрачность, но на резких цветных границах качество ниже, чем у профессиональных кодировщиков.
- Увеличение до 8K — это обычное растягивание с фильтром. Новых деталей оно не добавляет.
- Большая текстура не всегда меняет картинку в игре: итоговую резкость часто определяют шейдеры и сглаживание, а не размер файла.

## Консольные скрипты

Старые версии, только BC7:

```
python ktx_bc7_decoder.py <текстура.ktx> <результат.png>
python ktx_bc7_encoder.py <картинка.png> <оригинал.ktx> <новый.ktx>
```
